# 🛡️ 用户管理系统 - Web安全漏洞分析与修复实战

> **课程项目**：基于 Flask 的简易用户信息管理平台  
> **技术栈**：Python Flask / SQLite / Jinja2 / Werkzeug  
> **核心主题**：从漏洞到修复 —— 完整覆盖 OWASP Top 10 安全实践

---

## 📋 项目简介

本项目是一个**教学演示型** Web 用户管理系统，包含**注册、登录、信息展示、用户搜索、头像上传**五大核心功能。项目的独特之处在于它完整地展示了一个 Web 应用从**满是漏洞 → 逐步修复 → 完全安全**的演进过程，是学习 Web 安全攻防的绝佳实践案例。

### 功能列表

| 功能 | 路由 | 说明 |
|------|------|------|
| 🔐 用户登录 | `/login` | Session 认证，统一模糊错误提示 |
| 📝 用户注册 | `/register` | 支持新用户注册 |
| 🏠 信息展示 | `/` | 登录后查看个人信息 |
| 🔍 用户搜索 | `/?keyword=` | 按用户名/邮箱搜索 |
| 🖼️ 头像上传 | `/upload` | 上传头像到静态目录 |

## 🔬 安全演进三阶段

### 🏚️ 阶段一：原始漏洞版本（15个漏洞）

初版代码为教学演示而设计，故意引入了大量典型安全漏洞：

| 严重度 | 数量 | 典型漏洞 |
|:------:|:----:|---------|
| 🔴 严重 | 3 | 明文密码存储、密码传到前端、HTML注释泄露凭据 |
| 🟠 高危 | 5 | 弱Secret Key、Debug模式、无CSRF、可暴力破解、明文传输 |
| 🟡 中危 | 5 | Session标记缺失、无输入校验、可枚举用户名、监听0.0.0.0、硬编码凭据 |
| 🔵 低危 | 2 | Session无过期、无日志 |

### 🔧 阶段二：安全加固（基础修复）

对应 OWASP Top 10 的 8 个核心安全类别进行了全面修复：

- ✅ 密码加盐哈希存储（`werkzeug.security`）
- ✅ Session 安全加固（HttpOnly + SameSite + 过期时间）
- ✅ CSRF 保护（Flask-WTF 全局防护）
- ✅ 登录频率限制（flask-limiter）
- ✅ 安全配置分离（config.py + 环境变量）
- ✅ 统一模糊错误提示
- ✅ 安全事件日志

### 💉 阶段三：SQL注入教学演示 + 完全修复

为教学目的新增含 SQL 注入漏洞的注册/搜索功能，然后彻底修复：

| 漏洞 | 严重度 | 攻击方式 | 修复方式 |
|:----|:------:|---------|---------|
| 注册 SQL 注入 | 🔴 严重 | `'),('hacker','pw')--` | 参数化查询 |
| 搜索 SQL 注入 | 🔴 严重 | `' OR 1=1 --` 获取全部用户 | 参数化查询 |
| 数据库明文密码 | 🔴 严重 | 直接读取 db 文件 | password_hash 列 |
| 双存储不一致 | 🟠 高危 | 注册后无法登录 | 统一 SQLite 存储 |

## 🚀 快速开始

### 环境要求

- Python 3.9+
- pip（Python 包管理器）

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/tieqianhao/-.git
cd user-mgmt-security

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行应用
python3 app.py

# 4. 打开浏览器访问
open http://127.0.0.1:5000
```

## 🛡️ 安全加固清单

### 密码安全
- [x] 密码加盐哈希存储（pbkdf2:sha256）
- [x] 恒定时间比较（防时序攻击）
- [x] 前端 maxlength 限制

### 数据库安全
- [x] 参数化查询（防 SQL 注入）
- [x] 数据库自动迁移（旧→新 Schema）
- [x] 唯一约束 + 防重复插入

### Session & Cookie
- [x] 强随机 Secret Key（64 字节）
- [x] HttpOnly 禁止 JS 读取
- [x] SameSite=Lax 防 CSRF
- [x] 30 分钟自动过期

### 请求防护
- [x] CSRF 全局保护（Flask-WTF）
- [x] 登录频率限制（50次/小时）
- [x] 输入裁剪与校验
- [x] 统一模糊错误提示

### 运维安全
- [x] 生产环境关闭 Debug
- [x] 配置从环境变量读取
- [x] 安全事件日志
- [x] 仅监听 127.0.0.1
